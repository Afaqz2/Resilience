# Resilience Android App — Developer Requirements
# ================================================
# These are the tools and SDK versions required to build and run this project.

# --- Development Environment ---
# Android Studio: Hedgehog (2023.1.1) or later
# JDK: 17 (bundled with Android Studio or standalone)
# OS: macOS / Windows / Linux

# --- Android SDK ---
# compileSdk: 34
# minSdk:     26  (Android 8.0 Oreo)
# targetSdk:  34

# --- Build Tools ---
# Android Gradle Plugin (AGP): 8.5.0
# Kotlin:                      1.9.22
# KSP (Kotlin Symbol Processing): 1.9.22-1.0.17
# Gradle Wrapper:              (see gradle/wrapper/gradle-wrapper.properties)

# --- Key Dependencies (see gradle/libs.versions.toml for full list) ---
# Jetpack Compose BOM:         2024.02.01
# Hilt (Dependency Injection): 2.50
# Room + SQLCipher:            2.6.1 + 4.5.3
# DataStore Preferences:       1.0.0
# WorkManager:                 2.9.0
# Retrofit + OkHttp:           2.9.0 + 4.12.0
# MapLibre Android SDK:        10.2.0

# --- Setup Steps ---
# 1. Install Android Studio (https://developer.android.com/studio)
# 2. Open this project in Android Studio
# 3. Let Gradle sync (it will download all dependencies automatically)
# 4. Connect an Android device (API 26+) or create an emulator
# 5. Run the app via the green "Run" button or ./gradlew assembleDebug
